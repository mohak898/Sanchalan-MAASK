SANCHALAN

Browse the web with your head, your voice and an on-screen keyboard. No hands and no special hardware, just a webcam.

Download the extension View source on GitHub

Hold your pointer on the first button. It fills in 600 ms, the same dwell time the extension uses. Clicking works too.

Why there is no live demo on this page

SANCHALAN is a Chrome extension, and it cannot run as a normal website. A web page can only see and control itself. SANCHALAN has to work on every site you visit, so it needs abilities that Chrome gives only to installed extensions:

  • Switching, closing and reloading browser tabs, and going back or forward.
  • Typing and pasting into text fields on other websites, and reading the clipboard.
  • Running a side panel and an on-screen keyboard next to any page.
  • Keeping the microphone and camera pipelines alive in the background.

It also uses Chrome’s built-in AI (Gemini Nano) to summarize links on the device, which needs Chrome Dev or Canary. Publishing to the Chrome Web Store needs a paid developer account and a review period, so for this evaluation we share the build directly. Installing takes about a minute, and the camera and microphone never send anything to our servers.

Install it in five steps

  1. Open Chrome Dev or Chrome Canary, version 128 or later.
  2. Turn on three flags, then restart Chrome. Paste each address into the address bar:
    • chrome://flags/#optimization-guide-on-device-model set to Enabled BypassPerfRequirement
    • chrome://flags/#prompt-api-for-gemini-nano set to Enabled
    • chrome://flags/#summarization-api-for-gemini-nano set to Enabled
  3. Download the zip with the button above and unzip it.
  4. Open chrome://extensions, switch on Developer mode, choose Load unpacked, and select the unzipped SANCHALAN folder.
  5. Click the SANCHALAN icon, allow camera access, then calibrate with Alt+H for head tracking and Alt+M for mouth click.

The AI model downloads once and can take 5 to 10 minutes. Summaries start working after that.

What to try once it is running

  • Move your head to steer the pointer, and hold it on a link for 600 ms to see an on-device summary.
  • Open your mouth to click, or let the dwell ring fill on a button.
  • Say “sanchalan next tab” or “sanchalan new tab” to control the browser by voice.
  • Open the on-screen keyboard at the side and type using the same head and mouth controls.
  • Click a text field, say “start dictation”, and speak. Say “stop dictation” to finish.
